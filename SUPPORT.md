# Support

`hapax-assets` is published by **Hapax Research Lab** as a static publication asset mirror for inspection, provenance verification, and citation, not as a staffed support surface.

## GitHub issues

GitHub Issues are kept available only as a redirect surface. Blank issues are disabled; the issue chooser points readers to the appropriate boundary files instead of opening a support queue.

## What is in scope

- Inspecting the asset manifest (`_manifest.yaml`) and attribution notices (`_NOTICES.md`).
- Citing the repository through `CITATION.cff` and `.zenodo.json`.
- Reporting a concrete security disclosure or rights/attribution correction to `hrl-han@hapaxresearch.com` per `SECURITY.md`.
- Following the governance boundary through `GOVERNANCE.md` and https://github.com/hapax-systems/hapax-constitution.

## What is out of scope

- Troubleshooting, integration help, feature requests, or consulting through GitHub Issues.
- Unsolicited pull requests or contributor onboarding.
